# FRAME/01 — The Missing Pieces

Минималистичный платформер в эстетике редакционного дизайн-архива. Создан на Canvas и обычном JavaScript, без игрового движка и сборщика.

## Запуск

Поскольку проект использует ES-модули, открывайте его через HTTP, а не `file://`:

- GitHub Pages (Settings → Pages → Deploy from a branch → main / root);
- VS Code → расширение Live Server → Go Live;
- или `py -m http.server 8000`, если Python установлен.

## Управление

- Стрелки влево/вправо или A/D — движение.
- Space, W или стрелка вверх — прыжок. Второго прыжка в воздухе нет.
- На телефоне — кнопки ←, → и JUMP.
- START, PAUSE / CONTINUE, RESTART — управление игрой.

## Правила

Собрать три красных фрагмента, затем добраться до портала в правой части уровня. Красные шипы и падение в пропасть ведут к поражению. Лучшее время победы сохраняется в localStorage.

## Технические детали

Файлы `js/main.js`, `js/Game.js`, `js/Player.js`, `js/input.js`, `js/collision.js` организованы как ES-модули. Игровой цикл использует `requestAnimationFrame`, `dt` ограничен, физика обновляется короткими подшагами. При переключении вкладки игра ставится на паузу, клавиши очищаются. Все рисунки выполнены через Canvas, внешних изображений или звуков нет. Шрифты загружаются из Google Fonts; при отсутствии сети используются резервные системные.
